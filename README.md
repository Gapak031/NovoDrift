# NovoDrift

Все файлы лежат в корне репозитория, папок нет.

## Первая выкладка
1. Создай публичный репозиторий `novodrift`.
2. По очереди распакуй архивы и загрузи их файлы через **Add file → Upload files** (каждый архив — отдельный коммит):
   `novodrift-music-1`, `novodrift-music-2`, `novodrift-music-3`, и последним `novodrift-core`.
3. Settings → Pages → Source: ветка `main`, папка `/ (root)` → Save.
4. Игра: `https://<логин>.github.io/novodrift/`. На iPhone: Safari → «Поделиться» → «На экран Домой».

## Обновления
Просто загружай новые файлы поверх старых, **последним — `files.json`**.
Игра при запуске с интернетом сверяет `files.json` и сама докачивает изменённые файлы.
Если игрок в меню — игра перезапустится сама, если едет — обновится при выходе в меню.
